centroids (and related cross-checks). Complements GCI campaigns; does **not**
replace the P→S→T→Q cascade.

| Owns | Does **not** own |
|------|------------------|
| `section_integrals`, `section_centroid` oracles | Production FI gate (quaternary) |
| Absolute acceptance helpers for demos/tests | Mesh density policy (`section_mesh`) |
